# MRB Law Firm Website

A modern, responsive law firm website built with HTML5, CSS3, and JavaScript, featuring appointment scheduling and file management capabilities.

## Features

### 🏠 Homepage
- **Modern Design**: Clean, professional dark theme
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices
- **Practice Areas**: Comprehensive showcase of legal services
- **Client Testimonials**: Social proof with star ratings
- **Contact Information**: Easy-to-find contact details

### 📅 Appointment Scheduling
- **Online Booking**: Comprehensive consultation form
- **Multiple Consultation Types**: In-person, video call, or phone
- **Form Validation**: Real-time validation with user feedback
- **Responsive Design**: Works seamlessly on all devices

### 🎨 Design & UX
- **Professional Aesthetics**: Modern dark theme with indigo accents
- **Smooth Animations**: Fade-in effects and hover interactions
- **Mobile-First**: Fully responsive with mobile navigation
- **Accessibility**: ARIA labels, semantic HTML, keyboard navigation

### ⚡ Performance & Functionality
- **Fast Loading**: Optimized CSS and JavaScript
- **Interactive Elements**: Smooth scrolling, mobile menu, form handling
- **Error Handling**: Graceful fallbacks for images and forms
- **Analytics Ready**: Event tracking placeholder functions

## Technologies Used

- **HTML5**: Semantic markup with accessibility features
- **CSS3**: Custom styles with Tailwind CSS framework
- **JavaScript**: Vanilla JS for interactivity and form handling
- **Responsive Design**: Mobile-first approach with Flexbox/Grid

## Customization Guide

### Colors & Branding
- Primary color: Indigo (`#4f46e5`)
- Background: Black (`#000000`)
- Text: White/Gray shades
- Modify CSS custom properties for quick theme changes

### Content Updates
- **Company Info**: Update contact details in both HTML files
- **Practice Areas**: Modify the practice areas section in `index.html`
- **Testimonials**: Replace testimonial content and images
- **Form Fields**: Add/remove fields in the consultation form

### Images
- **Testimonial Photos**: Replace URLs in the image src attributes
- **Hero Background**: Update background image in the hero section
- **Fallbacks**: Placeholder images automatically load if originals fail
